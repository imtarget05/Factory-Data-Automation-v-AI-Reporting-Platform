# Factory Data Automation — C4 Architecture

> Source of truth: `Factory-…/README.md` architecture
> (files → ETL → clean → KPI → dashboard/AI report → export + alerts).

## C4-Context

```mermaid
C4Context
    title Factory Data Automation — System Context
    Person(mgr, "Factory manager", "reads KPIs, reports, alerts")
    Person(ops, "Operator", "drops Excel/CSV into data/raw")
    System(fac, "Factory Platform", "ETL, 8 KPI groups, dashboard, AI report, export")
    System_Ext(oll, "Ollama Qwen2.5:3b", "local executive summary/problems/risks")
    Rel(ops, fac, "drops raw files", "filesystem")
    Rel(fac, mgr, "dashboard + Excel/PDF + alerts", "HTTPS/files")
    Rel(fac, oll, "report generation, fallback-safe", "localhost")
```

## C4-Container

```mermaid
C4Container
    title Factory Data Automation — Containers
    Person(mgr, "Factory manager", "Streamlit UI")
    Container_Boundary(f, "Factory Platform") {
        Container(etl, "ETL pipeline", "pandas/polars", "discover, clean, Parquet, JSONL logs")
        Container(kpi, "KPI engine", "Python", "OEE, yield, utilisation, Pareto")
        Container(dash, "Dashboard", "Streamlit 10 pages", "Plotly charts, AI chat, export")
        Container(rep, "Exporter + alerts", "openpyxl/reportlab", "Excel/PDF, threshold alerts")
        ContainerDb(store, "SQLite + Parquet", "files", "processed sets, run artefacts")
    }
    Rel(etl, kpi, "clean frames", "in-process")
    Rel(kpi, dash, "KPI groups", "in-process")
    Rel(dash, rep, "exports/alerts", "in-process")
    Rel(etl, store, "persists", "files")
```
